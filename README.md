# mAdBlock: versiones publicadas

Aquí solo se publican los instaladores de mAdBlock para Android. El código fuente es privado.

mAdBlock es un navegador con el motor de Firefox que quita anuncios, rastreadores y avisos de cookies.

## Instalar en Android

1. En la tablet o el móvil, abre la [última versión](https://github.com/delayisus/mAdBlock-releases/releases/latest) y descarga el archivo **`mAdBlock-android-….apk`**.
2. Ábrelo. Android avisará de que viene de un origen desconocido: permítelo y pulsa **Instalar** (o **Más detalles › Instalar de todas formas**). Es normal porque no está en Google Play.
3. Abre mAdBlock y navega.

Necesita Android 8.0 o superior y un procesador de 64 bits.

## Actualizar

No hace falta volver aquí. mAdBlock avisa cuando hay una versión nueva, te cuenta qué cambia y se actualiza cuando tú pulsas **Actualizar**. Nunca se actualiza sola. Tus pestañas y ajustes se conservan.
